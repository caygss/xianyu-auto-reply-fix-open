# 单用户单电脑分发模式设计

## 目标

安装包按“一位买家、一台电脑、一个安装目录”使用。买家解压后直接使用本机管理员账号，不需要配置 SMTP，也不需要注册普通用户账号。

## 认证方案

- 保留现有本机管理员账号和登录流程。
- 新安装默认关闭普通用户注册（`registration_enabled=false`）。
- 对已有数据库，启动时也将注册开关收敛为关闭；不会删除已有账号、Cookie、商品或订单。
- 登录页隐藏注册入口，注册页面和注册接口继续返回“注册功能已关闭”，防止通过直接访问接口绕过界面。
- 邮箱验证码发送逻辑不再成为首次使用前置条件；SMTP/API 邮件配置不进入买家安装步骤。
- 不删除已有用户字段和 `user_id` 关联查询，保留基本的数据归属约束，避免未来重新开启多用户时造成回归。

## 数据边界

每个分发包的数据仍保存在该安装目录下的 `data/`、`browser_data/`、`logs/` 和配置文件中。不同电脑或不同安装目录之间没有共享数据库或共享 Cookie。

应用继续使用现有的本地服务端口；本次不做云端账号系统、不做跨设备同步、不做多租户改造。

## 用户体验

1. 买家解压安装包。
2. 直接双击 `XianyuAutoDelivery.exe`。
3. 使用默认管理员账号登录。
4. 登录后修改管理员密码，并配置自己的闲鱼账号和网盘链接。

文档会明确说明：每个安装包只供一台电脑上的一个买家使用，不要把同一个运行目录复制给多个买家继续使用。

## 验收标准

- 新数据库首次启动后，注册状态为关闭。
- 已有数据库重新启动后，注册状态也为关闭，但已有管理员数据不丢失。
- 未配置 SMTP 时，首次登录和核心管理功能不依赖邮件验证码。
- 访问注册页、注册接口均得到关闭提示。
- 默认管理员仍可登录并进入管理面板。
- 现有自动发货、网盘链接、商品发布和重新上架功能测试不回归。
- 编译包仍可直接双击 exe 启动，且不包含运行时数据库、Cookie、日志或密钥。
