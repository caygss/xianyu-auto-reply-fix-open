# 闲鱼商品说明参考文案

## 商品标题

闲鱼虚拟商品自动发货工具｜Windows 编译安装包｜开源可二次修改

## 商品说明

这是一个适用于 Windows 的闲鱼虚拟商品自动发货项目编译安装包，主要用于在买家付款后自动发送网盘固定链接，并支持默认链接与少量 SKU 专属链接配置。

安装包包含：

- Windows 编译可执行程序；
- 双击安装和启动脚本；
- 使用说明；
- AGPL-3.0 许可证与对应源码地址。

买家解压后即可使用，不需要单独安装 Python、Node.js、Docker 或 Playwright。首次使用时需用买家自己的闲鱼账号扫码登录，并自行配置自己的网盘链接和商品。

本项目遵循 AGPL-3.0。安装包可以收费分发，但不提供独家授权，不禁止买家查看源码、修改、二次分发或转售。具体对应仓库、标签和提交号以安装包内 `SOURCE-CODE.md` 为准。

不包含：卖家账号、Cookie、Token、密码、验证码、邮箱授权码、数据库、浏览器登录状态、日志和卖家专属网盘链接。

闲鱼接口、页面和风控策略可能变化；买家需自行承担账号、商品、链接和平台合规责任。建议先使用低价测试订单，确认自动发货和重新发布结果后再启用真实模式。
